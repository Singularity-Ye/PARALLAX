# Steam市场关键词检索

2026-10-26新增不依赖SteamDT榜单的CS2商品发现入口；这是范围补强，不冒称原项目已有同一检索接口。原reference/steamdt/fetcher.py及既有adapters/market已核对，现有榜单/扫描/预算行为保持。

## 合同与复用

POST /api/catalog/search，JSON {query,start}，start默认0、至多1000，关键词非空且至多200字节。每次匿名请求Steam市场search/render一页（count=10，appid=730，按名称排序），不读取Cookie、不自动翻页/重试。应用服务进程级串行门及15秒间隔，平台429至少冷却300秒；重启会清除这一进程级冷却，不是持久化调度器。409已有请求、429冷却、400参数、422结构、502上游失败，同源/no-store/1KiB请求限制。

复用既有reqwest及network统一出口，无新增依赖。domain定义请求/商品身份/分页；application控制请求与冷却、依赖CatalogProvider端口；adapter解释Steam协议；transport薄转换。响应保留查询、起点、实际条数、当次平台总数、下一起点和时间。总数可能变化，跨页无全量一致性保证；到起点上限或空结果不表示掌握全部市场。空页但平台仍声称有结果作为错误，身份/appid不一致或单页重复拒绝。

仅展示准确市场名、显示名和可选挂牌数，不采信返回的价格标签/币种猜测；挂牌数不是成交量或固定价可买量。不创建MarketItem现金报价，不写扫描/预算/台账，也不将发现商品直接判定为可采购。暂不保存发现快照；已有扫描历史不受影响。

前端在选品页使用现有card/candidate/forms，统一API与类型声明；下一页按已成功查询翻页，失败保留原页。带入历史研究只填入manual市场名并导航，不自动请求历史；随后用户选择已有账户、点击读取，复用原历史/独立研究用例。
