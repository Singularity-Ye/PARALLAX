## 复用与切页合同

- `web/lib/pages.js`：唯一导航/分组/标题/待迁移元数据及旧链接解析。
- `web/shell.js`：导航、一次只显示一个 data-page、标题/面包屑/aria-current、hash 前进后退、移动导航、仪表盘真实摘要。
- `web/index.html`：原功能表单各保留一份，不在路由时重建，不重复业务 ID；原模块继续绑定这些节点。
- `web/app.js` 等现有模块仍管理自己的请求与反馈，统一调用 api.js。shell 不计算折算率、仓位、风险或预算，不新增平台请求。
- 选中的扫描通过 parallax:scan-selected 提供仪表盘已有计数，不新建扫描仓库；报价引用通过 parallax:quote-referenced 只通知 UI，后端校验不变。

与原版一样是单个应用内的独立视图；使用浏览器 hash，不引入前端构建或路由依赖。切页保留当前 DOM、输入、已取得结果和任务状态；**刷新/关闭页面不承诺保存未提交表单**。Cookie 仍不写 localStorage，成功导入后由原模块清空。

操作记录打开扫描/预算后转到对应页面；失败留在记录页反馈并保留列表。Steam/BUFF 引用成功后转预算页并显示已填引用的反馈；仍按原业务核对币种、账户、候选和双方时效。持有饰品的入口仅展开原预算仓位表单，不创建另一套仓位。

桌面左侧导航独立滚动；窄屏提供打开/关闭、Escape、焦点限制和关闭时 inert。键盘有跳到内容、焦点样式，切页更新标题并聚焦页面标题。Hash 不读取密钥或加载任意远程 URL。

## 视觉基线

来源：用户于 2026-10-24 提供的两张福元电玩参考图。提取暖白纸底、轻微颗粒、粗黑标题、细分隔线、清楚边框、少量硬投影和荧光绿信号色。没有从截图断言具体字体；使用本机无衬线回退，正文与标题层级分开，数字保持可读。

- `web/theme.css`：颜色、字体、纸感纹理等 tokens。纸纹为本地内联 SVG 噪声，无大图与外部字体请求。
- `web/components.css`：布局、导航、表单、卡片、研究结果及响应式组件。
- `web/style.css`：只引入上述两层。Antigravity 可优先替换 tokens/组件，不改变路由、表单 ID 和统一 API。
- 黑色承担文字与主按钮，绿色只用于少量标记/图标，避免大面积亮绿影响信息密度；表单错误、演示/真实、未知与待迁移状态保持可辨认。

不将完整策略、订单、上架、日志、配置或赠礼页面写成已实现。策略中心已新增购入研究子集，见 [strategies.md](strategies.md)；没有激活/调度/交易动作。其余原算法和 API v1 合同保持不变。
